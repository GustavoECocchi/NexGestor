## (parte 2) Revisão independente do Opus 5 + correção dos achados

Revisão COM implementação: cada falha alegada na parte 1 foi reproduzida de
forma independente antes de qualquer correção, corrigida, e travada por
regressão que falha sem a correção.

### Achados confirmados por reprodução (todos corrigidos)

**P0 — perda de dados (frontend, `src/lib/store.ts`)**

1. `marcarComoSalva` escrevia o snapshot `vm` por cima do estado atual:
   `upsertLive` → `aplicarBenchmarkNaLive` → `marcarComoSalva` **apagava os
   benchmarks** (reproduzido). Corrigido para mesclar sobre o estado ATUAL,
   localizado por `clientId` (identidade estável) via `indiceAtual`.
2. A mesma função **recriava campanha já apagada** quando o save em voo
   voltava depois do delete (reproduzido). Agora é no-op quando a campanha
   não está mais na lista.
3. `mesclarComServidor` sobrescrevia o local com o payload do servidor
   (gravado antes do benchmark chegar), **apagando o enriquecimento**
   (reproduzido). Agora preserva `benchmarks` locais quando o servidor ainda
   não os tem; o servidor vence quando já tem.
4. O enriquecimento **nunca era enviado ao backend** — só existia neste
   navegador, e a primeira mesclagem o perdia. `App.tsx` passou a reenviar a
   versão enriquecida com o MESMO `client_id`. **Suspeita do prompt refutada
   com evidência**: reenviar com o mesmo `client_id` NÃO é
   "idempotente-ignorando-conteúdo" — `storage.salvar` faz
   `ON CONFLICT (dono, client_id) DO UPDATE SET payload = excluded.payload`,
   ou seja, atualiza o conteúdo (provado gravando `v1` e depois `v2`).
   `marcarFalhaPermanente` e `registrarAvisoTransitorio` também passaram a
   usar identidade estável (achavam por `id`, que muda na reancoragem).

**P0 — fonte incorreta (backend, `app/service/benchmark_service.py`)**

5. Cobertura **parcial** era aceita: `VALOR: 12.34` com support `[7, 8)` — 1
   byte de 5 — atribuía o número àquela fonte (reproduzido). Agora exige
   cobertura INTEGRAL do trecho (`_cobertura_integral`, aceita a união de
   supports adjacentes).
6. **Achado novo, não previsto no prompt**: os offsets eram tratados como
   caracteres do texto concatenado. O SDK documenta `Segment.start_index/
   end_index` como **bytes**, relativos a uma **Part** (`part_index`) — que o
   código ignorava. Com resposta multi-parte ou qualquer caractere multibyte,
   a atribuição olhava o trecho errado. Corrigido com
   `_span_em_bytes_da_parte` + filtro por `part_index`; valor que atravessa
   duas partes é rejeitado como ambíguo.

**P1 — custo duplicado (backend)**

7. `await tarefa` direto: cancelar UM interessado cancelava a tarefa
   COMPARTILHADA, e o retry abria uma **segunda busca paga** (reproduzido —
   2 chamadas). Corrigido com `asyncio.shield`. Testado com double
   assíncrono E com double SÍNCRONO bloqueado no executor (caminho real do
   SDK). Registrado no código que o single-flight é **por processo**: com
   `--workers N` o pior caso são N chamadas, não 1.

**P1 — validação (backend)**

8. `_cache_e_valido` aceitava CTR 999/-5/0, `capturado_em` inválido, fonte só
   com espaço e `https://` sem host; valor textual levantava `TypeError` em
   vez de virar miss (todos reproduzidos). Reescrito: nunca levanta, valida
   faixa/tipo (bool rejeitado)/fonte/URL com host/data ISO real.
9. `BenchmarkEncontrado` (response_model) aceitava exatamente os mesmos
   (reproduzido). Mesmas invariantes aplicadas; `extra="forbid"` nos dois
   modelos de resposta.
10. **Cache legado**: positivos gravados sob a regra de cobertura parcial e
    negativos vindos de falha transitória continuariam válidos por 14 dias.
    Adicionada coluna `regra_versao` (`REGRA_BENCHMARK_VERSAO = 1`); linhas
    de versão anterior viram miss. **Invalida só benchmarks** — campanhas e
    dados do usuário não são tocados.
11. Falha de SQLite ao ler o cache virava "sem fonte"; agora vira
    `BenchmarkIndisponivel` (503), nunca ausência de benchmark.

**P2 — troca de `DB_PATH` (backend)**

12. `_iniciado` era booleano global: trocar `DB_PATH` deixava o módulo
    achando que a base nova já tinha schema → `OperationalError: no such
    table` (reproduzido). Agora `_iniciado_para` guarda o caminho e a troca
    reinicializa. Regressão escrita SEM resetar o flag, de propósito — a
    lacuna existia justamente porque as fixtures o resetavam.

**P2 — motivos genéricos**

13. Fallback de custo usava o texto de "não existe benchmark", afirmando uma
    conclusão que a busca nunca tirou. Agora há `motivo_tipo`
    (`nao_elegivel` × `nao_encontrado`) e textos distintos: falta de contrato
    de moeda é limitação nossa, não ausência de fonte no mercado.

**P2 — validação de dados restaurados (frontend)**

14. `api.ts` validava só prefixo/finitude/string de data. Agora `0 < value
    <= 100`, URL com host analisável (`new URL`) e data realmente parseável.
15. `BenchmarkNote` renderizava `href`/`toFixed` direto sobre payload vindo
    do `localStorage`/da API de campanhas — caminhos que a validação da
    resposta nova nunca tocou. Agora revalida com a MESMA função
    (`referenciaDeMercadoValida`) antes de renderizar.

### Lacunas de teste fechadas

- **Integração HTTP real** (`App.benchmark.http.test.tsx`, 28 testes):
  `fetch` é o único mock; corpo cru trafega de verdade. Cobre 15 corpos
  malformados (item `null`, HTML de proxy, JSON inválido, `value` string/fora
  de faixa, URL sem host/`javascript:`, fonte em branco, data inválida,
  métrica não pedida/duplicada, discriminante ausente), 404/422/500/501/503,
  queda de rede, gating por `/status` (3 variantes), caminho feliz com link
  seguro + **prova de que o payload enriquecido sobe com um único
  `client_id`**, e exclusão pela **ação real da UI** (lixeira → confirmação),
  não mexendo no `localStorage` direto.
- **Corridas de persistência** (`store.corridas.test.ts`, 11 testes).
- **Fixtures do SDK**: `test_benchmark_mercado.py` trocou `MagicMock` por
  objetos REAIS do `google.genai` — foi o que expôs o bug de bytes/`part_index`
  (mock nenhum reproduz isso). Inclui multi-parte e acento.
- **Paridade entre linguagens**: as quatro fontes (schema Python, labels
  Python, `types.ts`, `niche.ts`) + o contrato, cada uma derivada do próprio
  arquivo — sem uma quinta lista literal.
- **Avisos de `act`**: 13 → **0**, corrigindo a coordenação dos testes (flush
  dentro de `act`), sem suprimir avisos.
